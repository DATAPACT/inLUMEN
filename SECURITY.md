# Security reporting

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/DATAPACT/inLUMEN/security/advisories/new).
This channel was enabled and verified on September 14, 2026. Reports are sent
privately to repository maintainers. Do not disclose vulnerability details,
credentials, private inputs or exploit material in public issues.

Include the affected commit/tag, deployment topology, reproduction steps,
expected impact and a minimal example with synthetic data. Redact secrets and
personal information. Do not test against someone else's deployment without
permission.

This project is a prototype prerelease. Maintainers assess reports against
current main and the latest prerelease; there is no guaranteed response time,
long-term-support commitment, or backport promise for older versions.

For ordinary bugs without sensitive security details, use
[GitHub issues](https://github.com/DATAPACT/inLUMEN/issues).
